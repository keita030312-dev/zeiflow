# ZeiFlow 操作手順(3分版)

このドキュメントは、はじめてZeiFlowを使う事務所スタッフ向けの最短マニュアルです。

---

## 1. ログインする

1. ブラウザで本番URL(例: `https://zeiflow.example.com`)を開く
2. メールアドレス・パスワードを入力
3. 2要素認証を設定している場合、認証アプリのコードを入力
4. ダッシュボード画面が表示されればOK

> **初回ログインできない場合**:
> - 「パスワードを忘れた方」からリセットメール送信
> - メールが届かない → 迷惑メールフォルダ確認 → 管理者に連絡

---

## 2. 顧問先(クライアント企業)を登録する

1. 左メニュー「**clients(顧客)**」を開く
2. 右上「新規登録」ボタン
3. 会社名・担当者名・メールアドレスを入力 → 保存
4. ポータルトークンが発行されるので、顧問先にURLを共有(下記参照)

---

## 3. 顧問先ポータルを使ってもらう(任意)

顧問先がレシートを直接送る場合:

1. 「clients」→ 該当顧客 → 「ポータルURLを発行」
2. URLを顧問先にメール/LINEで共有
3. 顧問先はそのURLからログイン不要でレシート画像を送信可能

---

## 4. レシートを登録する

### A. 事務所スタッフが直接登録
1. 左メニュー「**receipts(レシート)**」
2. 「新規アップロード」→ 画像をドラッグ&ドロップ
3. 顧問先を選択
4. アップロード → OCR自動実行(数秒〜十数秒)
5. 結果を確認 → 必要なら修正 → 保存

### B. 顧問先ポータルから受信
- 顧問先がポータルから送信したレシートは自動で「receipts」に届く
- 「ステータス: OCR待ち」→ 自動的に「OCR完了」へ移行

---

## 5. 仕訳を確認・編集する

1. 左メニュー「**journals(仕訳)**」
2. OCRから自動生成された仕訳一覧
3. 各仕訳をクリック → 詳細編集(勘定科目・摘要など)
   - **税区分は借方・貸方それぞれに設定**します(2026-07更新)。税率は選んだ税区分から自動で決まるため、税率の手入力は不要です
4. 内容に問題なければ「**確定**」ボタン

> **確定した仕訳は監査ログに記録**されます。後から変更すると履歴が残ります。

---

## 6. 会計ソフトに取り込む

1. 左メニュー「**export(エクスポート)**」
2. 期間・顧客を選択
3. 出力形式を選択(弥生 / freee / MFクラウド / 汎用CSV)
4. 「ダウンロード」→ CSVファイル取得
5. 各会計ソフトの「インポート」機能から取り込み

> 弥生会計向けCSVは **Shift-JIS・25列形式** で出力されるため、文字コード変換なしでそのまま取り込めます(2026-07更新)。

---

## 7. ナレッジを登録する(精度を上げる)

事務所固有の仕訳ルール(例: この顧問先のスタバ代は会議費で計上)をAIに覚えさせる:

1. 左メニュー「**knowledge(ナレッジ)**」
2. 「新規ファイル追加」→ ルールを書いたテキスト/PDFをアップロード
3. 以後のOCR&仕訳生成にそのルールが反映される

---

## こまったときは

| 症状 | 対応 |
|---|---|
| OCR結果が空欄 | レシートが薄い・角が欠けている可能性 → [既知の制限](./既知の制限.md) 参照 |
| アップロードできない | 10MB超 or 対応形式外(JPG/PNG/WEBP/GIFのみ) or 6枚以上(1回最大5枚) |
| ログインできない | パスワードリセット → ダメなら[障害時連絡フロー](./障害時連絡フロー.md) |
| エクスポートCSVが取込でエラー | 出力形式を会計ソフトの最新版に合わせて選択 |

詳細は [既知の制限.md](./既知の制限.md) と [障害時連絡フロー.md](./障害時連絡フロー.md) を参照。
