# 本番E2Eテスト手順

納品前に **本番環境の全フロー** が動くことを確認するチェックリストです。
1社目の納品時、または重大なリリース後に実施してください。

最終更新: 2026-04-29

---

## 事前準備

- [ ] 本番URL を準備
- [ ] テスト用アカウント(管理者+一般スタッフ) を準備
- [ ] テスト用顧問先(削除予定の dummy 1社) を作成
- [ ] テストレシート画像 5〜10枚 を準備

---

## 1. 認証フロー

### ログイン
- [ ] メアド+パスワードでログイン → ダッシュボード表示
- [ ] 2FA未設定アカウントでログイン
- [ ] 2FA設定済みアカウントでログイン → コード入力 → ダッシュボード
- [ ] パスワード間違い → エラーメッセージ表示
- [ ] ログアウト → ログイン画面に戻る

### パスワードリセット
- [ ] 「パスワードを忘れた」→ メアド入力 → メール送信
- [ ] メール到着確認(迷惑メールフォルダも)
- [ ] リンクからリセット画面 → 新パスワード設定
- [ ] 新パスワードでログイン成功

### 新規登録
- [ ] 新規登録ページから組織+ユーザー登録
- [ ] スーパー管理者の承認待ち状態
- [ ] スーパー管理者から承認 → ログイン可能になる

---

## 2. 顧客(顧問先)管理

- [ ] 新規顧客登録(社名・コード・連絡先)
- [ ] 顧客一覧に表示される
- [ ] 顧客の編集・更新
- [ ] 顧客の削除
- [ ] ポータルトークン発行
- [ ] ポータルURL の確認(クリップボードコピー等)

---

## 3. レシート登録(事務所側)

### 単一画像アップロード
- [ ] JPG をアップロード → OCR完了 → 仕訳生成
- [ ] PNG をアップロード → OCR完了
- [ ] WEBP をアップロード → OCR完了
- [ ] GIF をアップロード → OCR完了

### バリデーション
- [ ] 10MB超画像 → 「画像が大きすぎます」エラー
- [ ] 対応外形式(BMP等) → エラー
- [ ] 顧客未選択 → エラー

### OCR結果確認
- [ ] storeName / date / total / invoiceNumber が表示される
- [ ] 信頼度バッジ(緑/黄/赤)が項目ごとに表示
- [ ] OCR結果の編集が可能
- [ ] 編集内容が保存される

### qualityモード
- [ ] fast(既定)で処理 → 5〜10秒程度
- [ ] accurate で処理 → 10〜20秒程度

---

## 4. 顧問先ポータル

### ポータルアクセス
- [ ] ポータルURLにアクセス → ログイン不要で画面表示
- [ ] 顧問先名・案内文が表示される

### レシート送信
- [ ] スマホからJPG画像送信
- [ ] PCからJPG画像送信
- [ ] 送信完了画面が表示される
- [ ] OCR結果のサマリー(店名・日付・金額・登録番号)が見える

### 事務所側で受信確認
- [ ] receipts一覧に新着が表示される
- [ ] 仕訳が自動生成されている
- [ ] 監査ログに「PORTAL_RECEIPT_UPLOAD」が記録されている

---

## 5. 仕訳管理

- [ ] 仕訳一覧表示
- [ ] 月次フィルター
- [ ] 顧客フィルター
- [ ] 個別仕訳の編集(借方/貸方/金額/摘要/インボイス番号)
- [ ] 仕訳の確定
- [ ] 確定済み仕訳が学習データとして参照される
- [ ] 仕訳の削除(確認ダイアログあり)

---

## 6. ナレッジ管理

- [ ] テキストファイルをアップロード
- [ ] PDFをアップロード(対応していれば)
- [ ] ナレッジ一覧に表示
- [ ] ナレッジの削除
- [ ] ナレッジ追加後、新規レシートのOCRに反映されている

---

## 7. エクスポート

### 弥生会計形式
- [ ] 期間+顧客指定でCSV出力
- [ ] 弥生会計に取込テスト → エラーなく取り込める

### freee形式
- [ ] freee形式CSV出力
- [ ] freeeに取込テスト

### MFクラウド形式
- [ ] MFクラウド形式CSV出力
- [ ] MFクラウドに取込テスト

### PDF出力
- [ ] PDF出力 → 開けるか確認
- [ ] レイアウト崩れていないか

---

## 8. インポート

- [ ] CSV取込画面表示
- [ ] サンプルCSVをインポート → 仕訳が登録される
- [ ] フォーマットエラーCSV → 適切なエラーメッセージ

---

## 9. 監査ログ

- [ ] ログイン/ログアウトが記録されている
- [ ] レシート登録が記録されている
- [ ] 仕訳の編集・確定・削除が記録されている
- [ ] ポータル経由の送信が記録されている
- [ ] IPアドレスが記録されている
- [ ] 改ざん不可(削除ボタンがない)

---

## 10. 組織管理

- [ ] スタッフ追加(メアド招待)
- [ ] 権限ロール設定(管理者/一般/監査閲覧)
- [ ] スタッフ削除
- [ ] 自分自身は削除できない確認

---

## 11. 設定画面

- [ ] パスワード変更
- [ ] 2FA設定/解除
- [ ] APIキー設定(個人キー)
- [ ] 通知設定

---

## 12. スーパー管理者(該当者のみ)

- [ ] 全組織一覧
- [ ] 新規組織の承認
- [ ] 組織のサスペンド
- [ ] 全体統計

---

## 13. システム機能

### ヘルスチェック
- [ ] `GET /api/health` → 200 OK
- [ ] レスポンス内容が正常

### バックアップ
- [ ] `GET /api/backup` → ダウンロード成功
- [ ] バックアップファイルが開ける

### メンテナンスモード
- [ ] ON にすると一般ユーザーが弾かれる
- [ ] OFF にすると元に戻る

## 14. パフォーマンス(目安)

- [ ] レシートOCR(fast): **5〜10秒** 以内
- [ ] レシートOCR(accurate): **10〜20秒** 以内
- [ ] ダッシュボード初回表示: **3秒** 以内
- [ ] エクスポートCSV生成(月100件): **10秒** 以内
