# オンボーディング標準フロー(導入1週間で運用開始)

新規税理士事務所への ZeiFlow 導入を **再現性のある手順** に標準化したものです。
このフローに沿うことで、初回でも1週間で運用開始まで持っていけます。

---

## 全体像(7営業日プラン)

| Day | フェーズ | 主な作業 | 担当 |
|---|---|---|---|
| Day 0 | 契約 | 契約書締結・初期費用入金 | 甲・乙 |
| Day 1 | キックオフ | 要件確認・スケジュール合意 | 乙主導 |
| Day 2 | 環境構築 | アカウント発行・組織登録 | 乙 |
| Day 3 | 初期設定 | ユーザー追加・権限設定 | 乙+甲 |
| Day 4 | 顧問先登録 | 顧問先1〜3社をテスト登録 | 甲 |
| Day 5 | 研修 | スタッフ向け1.5h研修 | 乙 |
| Day 6 | テスト運用 | 実レシート10〜20枚で試験 | 甲+乙 |
| Day 7 | 本番開始 | 顧問先ポータル展開・運用開始 | 甲 |

---

## 各日詳細

### Day 0: 契約

- [ ] 業務委託契約書 締結([業務委託契約書テンプレ.md](./業務委託契約書テンプレ.md))
- [ ] 個人情報取扱委託に関する覚書 締結
- [ ] 初期費用 請求書発行・入金確認
- [ ] キックオフMTG 日程調整

---

### Day 1: キックオフMTG(60分)

#### アジェンダ
1. プロジェクト全体のスケジュール共有
2. 担当者の確認(甲側プロジェクトオーナー / 乙側担当者)
3. 利用範囲の確認:
   - ユーザー数(スタッフ何名分?)
   - 想定顧問先数
   - 月間処理レシート枚数(概算)
4. 既存業務フローのヒアリング:
   - 現在のレシート受領方法
   - 使っている会計ソフト
   - 仕訳ルール(顧問先別の特殊ルールなど)
5. 質疑応答

#### 持ち物
- [ ] 既存業務フロー図(あれば)
- [ ] 顧問先リスト(主要先)
- [ ] サンプルレシート 10枚程度

---

### Day 2: 環境構築(乙)

- [ ] 本番環境に組織を作成
- [ ] 管理者アカウント発行
- [ ] 初期ログイン情報を **暗号化メール or 対面** で受け渡し
- [ ] 2要素認証の設定支援

#### 引き渡し物
- 本番URL
- 管理者ID/初期パスワード
- パスワード初回変更手順書

---

### Day 3: 初期設定(乙主導+甲)

オンライン画面共有 60分

- [ ] スタッフ用アカウントを追加(全員分)
- [ ] 権限ロール設定(管理者/一般/監査閲覧のみ)
- [ ] 組織情報の登録(事務所名・連絡先)
- [ ] 通知設定(メール送信先)
- [ ] バックアップ設定の確認

---

### Day 4: 顧問先登録(甲)

甲側で実施。乙はチャットで質問対応:

- [ ] 顧問先1〜3社をまず登録(テスト用)
- [ ] 各顧問先の情報入力(社名・担当者・メール)
- [ ] ポータルトークン発行
- [ ] 顧問先への案内文面の準備(雛形は乙が提供)

---

### Day 5: スタッフ研修(乙)

オンラインまたは訪問 90分

#### 研修内容
1. ZeiFlow 全体説明(15分)
2. レシート登録のデモ(15分)
3. 仕訳確認・編集(15分)
4. エクスポート(10分)
5. 顧問先ポータルの仕組み(10分)
6. ナレッジ機能(10分)
7. 質疑応答(15分)

#### 配布物
- [操作手順.md](./操作手順.md)
- [既知の制限.md](./既知の制限.md)
- 研修動画(録画提供)

---

### Day 6: テスト運用(甲+乙)

実データで試験運用:

- [ ] 実レシート10〜20枚をアップロード
- [ ] OCR結果を確認・修正
- [ ] 仕訳を確定
- [ ] エクスポート → 会計ソフト取込テスト
- [ ] 不具合・違和感をリストアップ → 乙に共有
- [ ] 必要なら ナレッジに事務所固有ルールを追加

---

### Day 7: 本番運用開始(甲)

- [ ] テスト運用の結果が問題ないことを確認
- [ ] 全顧問先にポータルURL案内メール送信(雛形:乙提供)
- [ ] 月次運用レポートの初回発行日を設定
- [ ] 緊急連絡先・サポート窓口を周知

---

## オンボーディング完了基準

以下すべて満たした時点で「導入完了」とします:

- [ ] 全スタッフがログイン可能
- [ ] テスト用レシート10枚以上で OCR → 仕訳 → エクスポート完走
- [ ] 顧問先1社以上で ポータル経由のレシート受信成功
- [ ] [操作手順.md](./操作手順.md) を全スタッフが受領
- [ ] サポート窓口・障害連絡先を全スタッフが把握
- [ ] 月次運用レポートの初回発行日が確定

---

## 導入完了後の標準運用

| タイミング | 内容 |
|---|---|
| 毎週 | チャットでの質問対応(随時) |
| 毎月 | 月次運用レポート発行 + 改善提案 |
| 四半期 | オンライン定例MTG(30分) |
| 年次 | 利用状況レビュー + 来年度プラン提案 |

---

## オンボーディング成功のコツ(乙向け memo)

1. **Day 5の研修を録画して渡す** → 後から入ったスタッフも自走できる
2. **Day 6のテストは必ず甲側のリアルなレシートで** → 「ウチでも使える」が確信になる
3. **Day 7後は3日連続で様子確認チャット** → サイレント離脱を防ぐ
4. **困った顧問先の声を即拾う** → ナレッジに反映 = 精度向上 = 価値証明
