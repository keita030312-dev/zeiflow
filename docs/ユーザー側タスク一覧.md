# ユーザー側タスク一覧(納品完遂のため)

ZeiFlow を **完璧に納品し、お金が取れるレベル** に持っていくために、開発者(あなた)が用意・実施する必要がある項目をまとめました。

最終更新: 2026-04-29

---

## 🔴 最優先(これがないと営業も契約も無理)

### 1. OCR精度の実測値を出す
- **必要なもの**: テストレシート画像 20〜100枚
- **手順**: [OCR精度測定手順.md](./OCR精度測定手順.md) に従って測定
- **目標**: 各項目で90%以上の正答率
- **アウトプット**: [../ocr-accuracy-log.md](../ocr-accuracy-log.md) に記入完了

### 2. 第1号納品先の確保
- **誰**: 知人/紹介ルートの税理士事務所 1社
- **条件**: 半額モニター + 事例公開許諾
- **得るもの**: ロゴ + 数値成果(月XX時間削減)
- **次の活用**: 営業資料の中核に

### 3. 本番環境のフルE2E実施
- [E2Eテスト手順.md](./E2Eテスト手順.md) に従って全項目を確認
- 結果を delivery-checklist.md に転記

## 🟡 重要(BtoB契約に必須)

### 4. 法務系ドキュメントを実体に合わせる
- [業務委託契約書テンプレ.md](./業務委託契約書テンプレ.md) の `<>` を埋める
- 弁護士レビュー(Knowledge: ココナラで2〜5万でできる)
- [SLA.md](./SLA.md) の数値を実環境で達成可能か確認
- [月額サポート提供範囲.md](./月額サポート提供範囲.md) の `<>` を埋める

### 5. 連絡先・サポート体制
- [障害時連絡フロー.md](./障害時連絡フロー.md) の連絡先を実在のものに更新
- 緊急電話番号(専用回線または転送設定)
- サポートメールアドレス(`support@zeiflow.example.com` 等)
- チャット窓口(Slack/Chatwork/LINE WORKS)

### 6. 法人化(任意だが推奨)
- 個人事業 → 法人(合同会社/株式会社)
- 理由: BtoB契約の信用度、税負担最適化、損害賠償の限定
- タイミング: 年商300万を超える前後

## 🟢 信用度を上げる(競合差別化)

### 7. 課金プラン体系を公式化
- 営業資料・LP に明示
- 推奨プラン:
  - **スタータープラン**: 月10万(顧問先5社、月50枚まで)
  - **スタンダード**: 月25万(顧問先20社、月300枚まで)
  - **エンタープライズ**: 月50万+(顧問先無制限、専任サポート)
- Stripe等で自動課金実装(またはまずは請求書手動発行から)

### 8. 営業資料のブラッシュアップ
- 既存の `ZeiFlow_営業資料.pptx` を:
  - **OCR精度の数値** を1ページ目に追加
  - **競合比較**(STREAMED, invox, freee/MF AI-OCR との違い)を追加
  - **導入事例** スライドを追加(第1号納品先)
- LP は別途作成(noteでも一旦OK)

### 9. 自社実績の発信
- ZeiFlow 開発記をnote/Xで連載
- AI仮想会社3社の運用記録も併せて発信
- → 「実装力ある開発者がコンサルもやる」ポジション確立
