# 運用設定確認チェックリスト

本番運用開始前に、設定が正しく行われていることを確認するチェックリストです。

最終更新: 2026-04-29

---

## 1. 環境変数(`.env` / Vercel Environment Variables)

### 必須項目

- [ ] **DATABASE_URL**
  - 形式: `postgresql://user:password@host:port/dbname?sslmode=require`
  - 接続テスト: `npx prisma db pull` で通る
  - 本番DB は別リージョンか? バックアップ取得設定あるか?

- [ ] **ANTHROPIC_API_KEY**
  - 形式: `sk-ant-...` で始まる
  - 残高確認: Anthropic Console → Billing
  - 月額予算アラート設定済み(コスト管理)

- [ ] **RESEND_API_KEY**
  - 形式: `re_...`
  - 送信ドメインが verified(SPF/DKIM 設定済み)
  - 月間送信上限の確認

- [ ] **NEXTAUTH_SECRET**
  - 32文字以上のランダム文字列
  - **絶対に再生成しない**(再生成すると全ユーザーがログアウトされる)

- [ ] **NEXTAUTH_URL**
  - 本番URL(末尾スラッシュなし)
  - 例: `https://zeiflow.example.com`

### 推奨項目

- [ ] エラー監視(Sentry等)のキー設定
- [ ] ロギングサービスのキー設定

---

## 2. データベース

- [ ] PostgreSQL バージョン 14以上
- [ ] SSL接続が有効
- [ ] バックアップが自動取得されている(毎日推奨)
- [ ] バックアップから復旧テスト実施済み(過去3か月以内)
- [ ] スキーママイグレーションが最新(`npx prisma db pull` で差分なし)
- [ ] Prisma Studio で全テーブルを目視確認(`npx prisma studio`)

### テーブル健全性

- [ ] User テーブルに管理者が存在
- [ ] Organization テーブルに少なくとも1組織
- [ ] AuditLog テーブルに記録が積まれている

---

## 3. Anthropic API

- [ ] API キーの権限確認(messages API が使える)
- [ ] レート制限の確認(分間/時間あたり)
- [ ] 使用モデルが利用可能:
  - `claude-opus-4-7`
  - `claude-sonnet-4-6`
  - `claude-haiku-4-5-20251001`
- [ ] Prompt caching が動作している(2回目以降の同一プレフィックスが安い)
- [ ] 月額コストの推計:
  - レシート1枚あたり: 約 ¥3〜10(quality別)
  - 月100枚なら ¥300〜1,000

### コスト監視
- [ ] Anthropic Console で予算アラート設定(例: 月¥5,000超で通知)
- [ ] 月次でコストを確認するルーティン

## 4. メール送信(Resend)

- [ ] テストメール送信成功
- [ ] パスワードリセットメール到着確認
- [ ] 招待メール到着確認
- [ ] 迷惑メールフォルダに入らない(SPF/DKIM/DMARC OK)
- [ ] バウンスメールの監視設定

## 5. Vercel(デプロイ)

- [ ] 本番ブランチ(main)が自動デプロイ設定
- [ ] ビルドログにエラーなし
- [ ] 環境変数が **Production / Preview / Development** で正しく設定
- [ ] Vercel の Domains 設定に独自ドメイン追加
- [ ] HTTPS が有効(Let's Encrypt 自動)
- [ ] Vercel Analytics 有効
- [ ] デプロイ通知(Slack等)設定

## 6. セキュリティ

- [ ] `.env` ファイルは git にコミットされていない(`.gitignore` 確認)
- [ ] APIキーはコード内にハードコードされていない
- [ ] パスワードは bcrypt でハッシュ化されている(平文DB保存なし)
- [ ] HTTPS 強制(HTTP→HTTPS リダイレクト)
- [ ] CSP ヘッダー設定(可能なら)
- [ ] CORS 設定(顧問先ポータル含む)
- [ ] レート制限が動作している(ポータル含む)

### 脆弱性スキャン
- [ ] `npm audit` を実行 → 重大(critical/high)を解決
- [ ] 月次でアップデート計画(月1回 patch、四半期1回 minor)

---

## 7. バックアップ

### 自動バックアップ
- [ ] 取得頻度: 毎日深夜
- [ ] 保持期間: 30日以上
- [ ] 保存先: 本番DBと別リージョン
- [ ] 取得失敗時の通知

### 手動バックアップ
- [ ] `GET /api/backup` で取得可能
- [ ] ダウンロードしたファイルが復元可能

### 復旧テスト
- [ ] 開発環境でバックアップから復旧テスト(四半期1回)
- [ ] 復旧時間が SLA(8時間)以内
